# Riffinity MVP v0.1

ギター・ドラム用の3分練習習慣化アプリです。依存ライブラリ不要の静的Webアプリです。

## 起動

`index.html` をブラウザで開くか、GitHub Pagesに配置してください。

## GitHub Pages

1. 新規公開または非公開リポジトリを作り、`index.html` をリポジトリのルートに配置します。
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` を選択します（利用可能なプラン・リポジトリ設定に依存）。
3. 発行されたHTTPS URLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」で起動できます。

## 機能

- ギター・ドラムを自分で選択し、登録済みの課題から毎日のミッションを選択
- 3分タイマー（停止・再開可能）、BPMと自己評価の記録
- ストリークとフリーズ（初期2個、最大3個、実練習7日につき1個補充）
- 7日間の練習時間グラフ、履歴、JSONバックアップ・復元

## 制限と今後の開発

- ブラウザのlocalStorageに保存します。端末間同期、プッシュ通知、メトロノーム、AI出題は未実装です。
- タイマーは経過時間を再計算する方式です。端末の時計を変更した場合などの不正確さは残ります。
- ミッション開始日を練習記録の日付として使用します。日付をまたぐ練習は開始日に計上されます。
- フリーズは未達成日の判定時に自動消費します。初回利用以前の日付には適用されません。
